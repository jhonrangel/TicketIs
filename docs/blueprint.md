# **App Name**: Firebase Project Integrator

## Core Features:

- Project Import: Allow users to specify the Firebase project ID or URL from another account.
- Configuration Validation: Verify the provided Firebase configuration to ensure it's valid and accessible.
- Resource Browser: Browse the imported Firebase project's resources (e.g., Firestore, Storage, Functions) in a read-only mode.
- Rules Preview: Display security rules (Firestore, Storage) for the imported project.
- Connection Wizard: A guided wizard for users to enter credentials (if necessary) or OAuth information to connect to the external project.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and stability.
- Background color: Light gray (#F5F5F5) to provide a clean, neutral backdrop.
- Accent color: Soft amber (#FFB300) for highlighting important actions and notifications.
- Font: 'Inter', a sans-serif font, used for both headers and body text.
- Use clear, consistent icons to represent Firebase resources and actions.
- A tabbed interface for browsing different Firebase resources.
- Use subtle transitions and loading animations to enhance user experience.
